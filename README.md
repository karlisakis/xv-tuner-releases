# XV Tuner — Downloads

Installers and the user manual for **XV Tuner V3**, the ECU tuning and
diagnostics tool for Aprilia SXV / RXV.

**Get the newest version from the [latest release](../../releases/latest).**

| File | For |
|---|---|
| `XV_Tuner_V<version>_Windows_x64_Setup.exe` | Windows 10 / 11 (64-bit) |
| `XV_Tuner_<version>_macOS_arm64.dmg` | macOS 11 or later, Apple Silicon |
| `XV_Tuner_V3_User_Manual.pdf` | User manual |

XV Tuner needs an XV cable and the license file that came with it.

Already installed? The app updates itself: **Tools → Settings → Software Update**.
Updates are digitally signed and verified by the app before they are installed.

Support: support@xvtuner.com — or use **Tools → Diagnostics → Report Issue**
inside the app.
